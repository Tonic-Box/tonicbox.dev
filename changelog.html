Changelog

What's new in TonicBoxOS - features, improvements, and fixes, newest first.

2026-08-08

Hypervisor migration, a faster runtime, and a broad correctness pass

A large release. TonicBoxOS moved onto a Type-1 hypervisor, gained a runtime JIT and an optimizing compiler for real speed, and went through a wide shell, utility, and compiler correctness pass. Manual pages are now real, file-based man pages. See the updated architecture writeup.

Added
  • Hypervisor-hosted OS: the whole system now runs as a single de-privileged guest under tb32hv, a Type-1 hypervisor compiled to WebAssembly. The kernel runs in guest-supervisor mode and userland in guest-user mode, isolated by two-stage nested paging.
  • Runtime JIT and optimizing compiler: the hypervisor's CPU compiles hot guest code to WebAssembly at runtime, and the toolchain gained an optimizing pass (-O), so programs and games run substantially faster.
  • Shell: word-splitting, subshells ( ), command substitution with pipes and functions, backticks, here-documents and here-strings, break/continue/return/shift/set, ${VAR:-default}-style parameter expansion, full comparison/bitwise/shift arithmetic, [...] globs, and more test operators.
  • Utilities: real regular expressions in grep, sort -k/-t, cp -r, mkdir -p, rm -f, symbolic chmod, printf field widths, and flag support across id, uname, date, ls, head, tail, and others.
  • Manual pages: man now serves real sectioned pages (NAME / SYNOPSIS / DESCRIPTION / OPTIONS) read from a database in the filesystem.
Improved
  • A real-time clock replaces the instruction-counted one, fixing a freeze during long play sessions and giving smoother frame pacing.
  • Copy-on-write fork and wider memory access cut per-command overhead, so the shell feels snappier.
Fixed
  • Data safety: cp FILE FILE and mv FILE FILE no longer destroy the file, mv onto an existing file replaces it correctly, and kill with a non-numeric argument no longer ends the session.
  • The optimizing compiler no longer miscompiles programs that initialize a local from a live parameter, and external commands now report their exit status to $?.
  • cd through a symlink lands in a usable directory, and terminal size is reported to programs (TIOCGWINSZ) so full-screen apps and games size to the window.
2026-08-01

Real virtual memory: paging, copy-on-write fork, and mmap

Each process moved from a single fixed 2 MiB window to a proper paged virtual address space - larger programs, demand allocation, copy-on-write fork, and an mmap/mprotect interface.

Added
  • Per-process paged virtual memory: a 16 MiB virtual address space per process, in 4 KiB pages served on demand (demand-zero) from a shared physical frame pool.
  • mmap, munmap, and mprotect (syscalls 100-102): anonymous and file-backed mappings with changeable page protection.
  • Guard pages: a null-pointer dereference, or a stack that runs past its limit, now faults cleanly instead of silently corrupting neighbouring memory.
Improved
  • fork is now copy-on-write: the child shares the parent's pages until one side writes, so it no longer copies the whole address space up front.
  • Much larger heaps and programs: the old hard 2 MiB per-process ceiling is gone (about 14 MiB usable), so bigger allocations and heavier programs run.
  • The memory hot path stays fast under address translation, via a software TLB and wider aligned loads.
  • /proc/meminfo now reports the real physical pool (total and free).
  • The debugger reads and writes a traced process through its own page table.
2026-08-01

Second stage, full shell redirection, and a broad correctness pass

A second-stage challenge, a much richer shell and terminal, and a wide sweep of correctness and security fixes across the kernel, toolchain, and userland.

Added
  • A second-stage challenge that begins once you have root.
  • Full shell redirection: stderr and arbitrary descriptors (2>, N>), 2>&1 (applied left to right), &>, read-write (<>), and closing a descriptor (>&-).
  • Backslash escaping and line continuation in the shell.
  • Terminal: 24-bit truecolor, scroll regions, insert/delete line and character, and bold + reverse-video rendering.
  • A score column on the Hall of Fame.
  • This changelog.
Improved
  • The core utilities (cp, grep, sort, tac, sha256sum, tail, head, cut, sed, uniq, and more) now stream their input, so they stay correct on files of any size instead of silently truncating.
  • POSIX directory permissions are now enforced - search (x) to traverse and read (r) to list, matching real Unix.
  • The compiler and assembler handle longer identifiers, labels, and string literals; the self-hosting toolchain still rebuilds itself byte-for-byte.
Fixed
  • Compiler correctness: compound assignment (arr[i++] += x) no longer evaluates the left side twice, pointer subtraction scales by element size, and char stores truncate to a byte.
  • Kernel: a path-canonicalization overflow, rename into its own subtree or over a non-empty directory, chown clobbering the group, and a couple of syscalls that could hang the VM on a huge length.
  • Shell: user-defined functions persist across prompts, a glob with many * no longer hangs, read < file works, and builtins honor redirection.
  • Terminal & site: bold text renders, AltGr keys type the right character on non-US keyboards, and the nav no longer double-highlights on the Hall of Fame page.
